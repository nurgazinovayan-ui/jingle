# Звуки для четырёх новогодних мини-игр

Сгенерированы в Higgsfield (ElevenLabs Music v2.5), затем обрезаны, сведены и закодированы под требования ТЗ.

## Где что лежит

```
courier/      Побег курьера     jump, star, hit, music
shymbulak/    Спуск по Шымбулаку gate, arch, hit, music
match3/       Три в ряд          pop3, pop4, pop5, bad, music
gift-tower/   Башня подарков     drop, perfect, miss, music
sources/<игра>/*.wav             те же звуки в WAV 48 кГц / 24 бит
```

Имена файлов совпадают с заглушками в играх. Названия папок выбраны произвольно: переименуйте их под структуру проекта.

## Эффекты

Каждый эффект начинается с первого сэмпла (атака ≤ 1 мс), длина не превышает лимит из ТЗ, хвост плавно затухает.
Внутри линеек выдержана иерархия громкости и яркости: pop3 < pop4 < pop5, gate < arch.

| Файл | Длина | Что звучит |
|---|---|---|
| courier/jump | 0,30 с | пружинистый «боинг» вверх |
| courier/star | 0,40 с | яркий колокольчик |
| courier/hit | 0,50 с | глухой удар о коробку |
| shymbulak/gate | 0,30 с | свист снега и колокольчик |
| shymbulak/arch | 0,60 с | сверкающее арпеджио колокольчиков, ярче, чем gate |
| shymbulak/hit | 0,50 с | мягкий удар в снег, низкий тон |
| match3/pop3 | 0,20 с | одиночный «поп» |
| match3/pop4 | 0,30 с | серия попов с маримбой |
| match3/pop5 | 0,50 с | восходящее глиссандо, самый яркий звук линейки |
| match3/bad | 0,30 с | мягкое нисходящее «бвуп» |
| gift-tower/drop | 0,30 с | картонный стук |
| gift-tower/perfect | 0,40 с | стук и звонкий колокольчик |
| gift-tower/miss | 0,59 с | падающий свисток, конец игры |

## Музыка

Все треки инструментальные, мелодии оригинальные, темп ровный.

| Файл | Темп | Петля |
|---|---|---|
| courier/music | 128 BPM | 24 такта = 45,000 с |
| shymbulak/music | 120 BPM | 16 тактов = 32,000 с |
| match3/music | 140 BPM | 20 тактов = 34,286 с (самая бодрая) |
| gift-tower/music | 110 BPM | 16 тактов = 34,909 с |

Как сделаны петли:
- Отрезок вырезан из середины 60-секундной генерации. Его границы подобраны так, чтобы конец по спектру совпадал с началом.
- Стык поставлен примерно за 0,2 с до доли, в тихом месте между ударами. Если плеер вставит микропаузу, она не попадёт на удар.
- Конец петли переходит в начало через кроссфейд 80 мс, поэтому разрыва волны и щелчка на стыке нет.

## Что учесть

- **WAV-исходники — не lossless-мастер.** Higgsfield отдаёт результат только в MP3 128 кбит/с. WAV в `sources/` сделаны из этих MP3 после обрезки и сведения и передискретизированы до 48 кГц / 24 бит. Подбирать финальное сжатие по ним можно, но верхние частоты в них уже срезаны MP3-кодированием.
- AAC добавляет в начало файла около 48 мс «приминга». В .m4a это компенсируется служебными метаданными (edit list). Safari, Chrome и AVFoundation их учитывают, и звук стартует без задержки.
