# Jingle — онлайн музыкальный плеер

Лёгкий музыкальный плеер для деплоя на [Vercel](https://vercel.com): статический фронтенд
на чистом HTML/CSS/JS и serverless-функция `/api/tracks`, которая отдаёт плейлист.
Зависимостей и сборки нет.

## Возможности

- Плейлист с поиском, длительностью треков и подсветкой текущего
- Играть / пауза, предыдущий / следующий, перемотка, громкость, mute
- Перемешивание и повтор (выкл / весь плейлист / один трек)
- Свои файлы: кнопка «Добавить файлы» или drag & drop (файлы играют прямо в браузере, никуда не загружаются)
- Запоминает громкость, режимы, последний трек и позицию (localStorage)
- Media Session API — управление с клавиатуры, наушников, экрана блокировки
- Адаптивная вёрстка для телефона

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| Пробел | Играть / пауза |
| ← / → | Перемотка на 5 секунд |
| ↑ / ↓ | Громкость |
| N / P | Следующий / предыдущий |
| S | Перемешать |
| R | Режим повтора |
| M | Без звука |
| / | Поиск |

## Структура

```
index.html        — разметка плеера
styles.css        — стили
app.js            — логика плеера
api/tracks.js     — serverless-функция: GET /api/tracks[?q=поиск]
data/playlist.js  — список треков
music/            — сюда можно класть свои mp3
vercel.json       — заголовки кэширования
```

## Свои треки

1. Положите файл в папку `music/`, например `music/my-song.mp3`.
2. Добавьте запись в `data/playlist.js`:

```js
{ id: "my-song", title: "Моя песня", artist: "Я", src: "/music/my-song.mp3", cover: "" }
```

`src` может быть и внешней ссылкой на mp3. `cover` — необязательная ссылка на обложку.

> Vercel ограничивает размер деплоя, поэтому для большой фонотеки лучше хранить файлы
> во внешнем хранилище (например, Vercel Blob, S3, Cloudflare R2) и указывать ссылки в `src`.

## Деплой на Vercel

**Через сайт:** импортируйте репозиторий на [vercel.com/new](https://vercel.com/new) — Framework Preset: *Other*,
никаких настроек сборки не нужно.

**Через CLI:**

```bash
npm i -g vercel
```

```bash
vercel --prod
```

## Локальный запуск

```bash
npx vercel dev
```

Без Vercel CLI тоже работает (`npx serve .`) — если `/api/tracks` недоступен, плеер
загрузит плейлист напрямую из `data/playlist.js`.
